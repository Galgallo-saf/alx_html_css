# Headphones Project

This is a responsive web design project for ALX HTML/CSS course, focusing on creating a **Headphones landing page** with attention to interactions, responsiveness, and design fidelity.

---

## 📁 Project Structure

- **Directory:** `headphones`
- **Files included:**
  - HTML files: `0-index.html`, `1-index.html`, … `8-index.html`
  - CSS files: `0-styles.css`, `1-styles.css`, … `8-styles.css`
  - JS files: `8-script.js` (for hamburger menu toggle)
  - Images: all relevant assets for the project
  - `.gitignore` (to ignore VSCode and system files)
  - `README.md` (this file)

---

## 🎨 Features & Design Notes

- Fully responsive layout
- Switches to **mobile version** when screen width ≤ 480px
- Maximum content width: 1000px, centered on the page
- Links hover/active color: `#FF6565`
- Buttons hover/active: `opacity: 0.9`
- Fonts used: `Source Sans Pro` and `Spin Cycle OT`
- Images optimized for desktop, tablet, and mobile

---

## ⚡ Interactions

- Hamburger menu toggle implemented via `8-script.js`
- Smooth hover effects on links and buttons
- Responsive breakpoints handled with CSS media queries
