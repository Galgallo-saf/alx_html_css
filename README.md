# Headphones Project

This project is a responsive landing page for headphones, created as part of ALX HTML/CSS tasks.

## Features

- Responsive design for mobile (≤480px), tablet, and desktop
- Hamburger menu toggle for mobile
- Interactive buttons and hover effects

## Setup

1. Clone this repo
2. Open the `headphones` directory in your browser
3. Explore HTML, CSS, and JS files

## Technologies

- HTML
- CSS
- JavaScript
